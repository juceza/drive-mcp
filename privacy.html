Política de Privacidade — My Personal Google Drive MCP

Última atualização: 25 de setembro de 2026

Uso pessoal

Este aplicativo é de uso exclusivo do seu desenvolvedor e não é disponibilizado a terceiros.

Dados acessados

Mediante autorização OAuth, o aplicativo acessa arquivos do Google Drive, Docs, Sheets, Slides e eventos do Google Calendar da conta autorizada, apenas para executar as ações solicitadas pelo próprio usuário.

Armazenamento

Os tokens de acesso são armazenados apenas localmente, no computador do usuário. Nenhum dado é enviado a servidores do desenvolvedor.

Compartilhamento

Nenhum dado é vendido, compartilhado ou transferido a terceiros.

Revogação de acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

Uso de dados das APIs do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
